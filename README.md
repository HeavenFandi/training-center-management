# Training Center Management System

A web application for managing training centers, built with React, TypeScript, Vite, Redux Toolkit, Material UI, and Axios.

## Technologies

- React 19
- TypeScript
- Vite
- Redux Toolkit
- React Router DOM
- Material UI (MUI)
- Axios
- React Hook Form
- Yup

## Features

### Authentication
- Login
- Register
- Forgot Password (OTP Verification)
- Reset Password

### Admin
- Dashboard
- Institute Management
- Teacher Management
- Student Management
- Course Management
- Training Session Management
- Classroom Management
- Category Management

### Teacher
- Teacher Dashboard
- Profile Management

### Student
- Student Dashboard
- Course Browsing
- Course Registration

## Installation

```bash
git clone <repository-url>
cd training-center-management
npm install
```

## Run the project

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
